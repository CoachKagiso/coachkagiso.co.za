## 2. CHANGE A — Export pipeline (components/content/ContentStudio.tsx)

A1. captureCarouselSlideCanvas (~line 10005). The current code supersamples 2x then ALWAYS downscales to the platform target (1080×1350) with imageSmoothingEnabled=true; the PDF then embeds that 1x raster. This is the reported softness bug. REPLACE the downscale block with: keep/normalise to 2x and never downscale:

    const targetW = dimensions.width * 2;   // 2160
    const targetH = dimensions.height * 2;  // 2700
    if (captured.width !== targetW || captured.height !== targetH) {
      const out = document.createElement('canvas');
      out.width = targetW;
      out.height = targetH;
      const ctx = out.getContext('2d')!;
      ctx.imageSmoothingEnabled = true;
      ctx.imageSmoothingQuality = 'high';
      ctx.drawImage(captured, 0, 0, targetW, targetH);
      captured = out;
    }
    return captured; // always 2x output

If it currently converts to a 1x dataURL first, change it to embed the 2x canvas.

A3. getCarouselExportFontFamilies (~line 9976). Stop reading --font-sans/--font-serif for export (they resolve to off-brand Raleway/Noto Serif). Hardcode brand stacks: 'Inter, "Helvetica Neue", Arial, sans-serif' and '"Playfair Display", Georgia, serif'.
